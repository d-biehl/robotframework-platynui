# Tasks

## 1. Withdrawn

This section confirmed that the bus hands out process file descriptors, which the descriptor-based identity chain rested on. That chain is not taken (design D1, last alternative): the decision is one `GetConnectionCredentials` call for our own connection and one comparison with `getpid()`, so there is no environment fact left to measure before starting. The section stays numbered so every reference to a later task keeps its number.
