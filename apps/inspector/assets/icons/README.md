# Toolbar icon assets

[Phosphor Icons](https://phosphoricons.com/) (MIT, see `LICENSE`), regular
weight plus the fill weight for active toggle states. Every SVG checked in
here MUST be normalized to a white fill/stroke (`fill="#ffffff"`): egui's
image tint is multiplicative, so only white sources take the theme's text
color fully via `image_tint_follows_text_color`.
